# 共享素材

适用于 Video+ 1.3.6 / Terre 4.6.6。

## 开始使用

在安装器中启用“共享素材与项目资源”，随后正常启动 Terre。

素材页上方显示项目素材，下方显示共享素材，沿用原生图标、网格 / 列表、文件夹导航和命令选材筛选。共享区以淡紫色背景标识来源；图片保持原色。

一次添加整个素材根即可保留原有子目录结构。也可继续添加其他独立目录。立绘 / Live2D、背景、音乐、语音 / 音效和视频按当前命令筛选。已有分类登记继续保留；多个来源中的同名文件由各自编号区分，不互相覆盖。

共享区只读，可预览、引用或复制到当前项目。复制会收集完整模型依赖并生成独立目录，重名自动加序号。复制完成后明确选择副本再编辑，其他剧本引用保持原样。来源搬走或取消登记后，共享引用会提示不可用，已复制的项目素材继续可用。

自行登记的共享目录请选择工程和安装目录之外的位置；引擎自带素材由创建页选项登记。模型与公共贴图分属相邻目录时，选择它们共同的父目录，使模型内部相对引用都位于该根内。

## 安装模块与创建项目

安装器的高级选项提供“共享素材与项目资源”。可按安装修改模块；关闭共享入口保留来源登记和已有引用的运行服务。仍有工程引用外部资源时，拆卸最后一个本机服务模块会提示先将引用复制到工程。共享文件夹原件保留。

创建游戏时可选择“创建空白项目”：跳过示例剧本、图片、立绘、音视频，保留空的起始剧本、配置与界面必需文件。此项不会自动建立共享引用。

勾选“创建空白项目”后，可启用“共享资源使用引擎内自带的资源”。素材默认取自上方所选引擎的 game 文件夹，在共享素材区引用；也可点击“选择其他文件夹”，选择包含 game 的引擎目录作为素材来源。手动来源只影响素材，项目运行时继续沿用上方所选引擎。取消创建空白项目后，此选项禁用且提交时不生效。

## 地址与旧测试工程

共享文件由现有 Video+ C# 服务提供，Terre 继续运行官方后台。剧本中的 HTTP 地址使用持久化的本机资源端口和来源编号，不包含短期 API token。服务重启保持地址；端口被占用时提示占用端口，释放后重试，不静默换地址。

旧测试工程的 `__shared/<编号>/<路径>` 引用，可在共享来源操作中点击“转换本项目旧引用”。转换仅处理当前项目并保留备份，打开项目和列目录不会自动转换。转换前备份位于测试状态目录的 `shared-reference-backups`，对应 `restore.json` 记录原文件及校验值。

素材列表刷新重新读取目录元数据，文件 HTTP 请求按 ETag 重新校验。正在显示的模型沿用原引擎资源缓存；外部修改后使用预览栏的“刷新游戏”，再预览素材。

## 模型地址与动作选项

立绘地址优先显示文件名、相对父路径和短来源标识，悬停可查看完整值。剧本保存及资源请求继续使用原始地址。

动作、表情和皮肤选项在选择模型或项目变化时读取；成功后复用当前选项。读取失败可点击“重试”，关闭编辑器或切换模型会取消旧请求。已保存的动作、表情值保留，空列表有对应提示。

## 导出与游戏打包

视频保留既有剧情范围、切段和有限预热。排队保存来源登记与资源地址信息，准备时复制依赖并计算内容指纹，渲染从任务快照读取。已准备快照可以在来源离线后使用。

原生游戏打包先创建独立临时项目副本，收集全部场景、分支、配置及模型内部依赖，只在副本中转换为包内引用，再交由原 Terre 打包。原工程继续保存共享引用。完成后清理临时副本；准备耗时与总耗时分别记录。实体化后的游戏不依赖 Video+ 或原共享目录。动态拼接路径仍需按现有扫描能力检查。

## 渲染设备与文本框动画

导出高级设置可选择渲染设备。编码器仍单独选择；完成任务的诊断会对照请求设备与实际渲染信息，同型号设备的精确身份可能仍待确认。

“精确文本框循环动画”默认关闭。关闭时文本框无限循环装饰不单独触发整层重截图，其他画面更新仍会带入当时相位；开启后按视频时刻精确采样，可能增加导出时间。有限动画、文字显示及文本框之外的动画沿用既有处理。

# WebVideo+ 1.1.4 发行说明

修复导出视频中逐字出现的样式文字偶尔缺少笔画的问题。字形的斜体、描边等效果可能伸出字符的排版框；现在双行文字能容纳在单页图集时逐字独立捕获，并给其他情况下的逐字遮罩留出通用的字形空间。此前为避免多页图集造成切段跳字而设置的回退规则仍然保留。

安装器和 Terre 中的更新检查现在共用提醒设置。可选择“下个版本前不要提醒我”“下个主要版本前不要提醒我”或“不要提醒我”。这里的“主要版本”按版本号第一位计算，例如从 1.x 到 2.0。前两档仍会静默读取发行信息，以便在达到指定版本时恢复提醒；最后一档停止自动联网检查。两处都保留手动检查和恢复提醒入口。

本版通过内核编译、导出生命周期检查、更新提醒规则检查，并用复制的短场景按反馈中的双行斜体文本完成 1080p 导出。该场景的 43 个字符现在由单页图集独立捕获，逐字遮罩不再参与；对比旧版与新版的同一过渡帧，行末字原先缺失的边缘像素已补齐。另用跨 `-concat` 的双行文本完成短片导出，保持单页图集。尚待用用户原始工程确认最终画面。

WebGAL / Terre 适配基线仍为 **4.6.4**；4.6.5 适配不包含在本版中。

- 产品版本：`1.1.4`
- 安装器 Win32 版本：`1.1.4.0`
- 内部版本：`0.8.8`
- 导出内核：`0.6.48`

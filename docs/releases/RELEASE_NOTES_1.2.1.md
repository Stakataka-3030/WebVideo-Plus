# WebVideo+ 1.2.1 · WebGAL 4.6.5 最终稳定版

本版面向 Terre / WebGAL 4.6.5，作为 4.6.5 最终稳定通道。4.6.4 / MyGO 3.2.1 使用 1.1.7；4.6.6 使用独立的 1.3.0；Craft 保持独立的 1.1.12.0c 通道。

兼容模式新增可选 PNG 无损截图，默认仍为 JPEG。设置保存在本机偏好和任务快照中，各 worker 使用相同输入格式，重试缓存区分截图格式。PNG 仅避免截图阶段的压缩；最终 H.264 视频仍有损，其他画质、透明图层和音轨模式的编码语义不变。

修正规划器未登记动态命名动画导致时长为零的问题。动画运行中或模型有后续动作变更时，切段按需要重放完整场景历史，保留原生动画驱动、动作选择、保存姿态和物理状态；手动切点及输出帧数不变，自动并行继续考虑预演成本。复杂场景可能增加预演耗时。模型退场继续使用其原始出生时刻。分析任务结束后的 WebView2 短暂文件锁采用最长 5 秒的有限缓存清理重试。

产品版本 1.2.1，安装器 Win32 1.2.1.0，内部标识 0.9.1，导出内核 0.6.54。

修正 4.6.5 上游 Cubism2 预加载纹理上传问题，避免人物出现碎片。修复只作用于导出快照中的旧 Cubism2 纹理；保留原引擎版本、原项目、共享纹理及现代 Moc3 资源。4.6.6 使用其官方纹理处理。

本轮已验证：149 项 Node 回归、212 项生产设置/手动切点断言、69 项当前及历史安装器分流断言、159 项真实原版 4.6.4 / 4.6.5 引擎适配断言、66 项资源预检、33 项用户记录隔离断言及 16 种编辑器补丁变体。真实 Edge 字体继承、Cubism2 动作生命周期契约、旧插件纹理工厂及 Live2D 帧时钟检查通过。

Windows 实际导出验证包括 JPEG / PNG 单、双 worker，四种舞台背景/立绘组合，透明对话框、独立音轨、多场景软字幕和音乐整合。完整解码后的单、双 worker RGB 帧一致；PNG 设置保存与服务重启、取消后重试、缺素材修复后重试、RAW 模式保留偏好均通过，完成任务的重型缓存已清理。真实 Terre 界面已用 PNG 完成导出并验证选项启用条件和重新加载。

隔离安装、重装、模块切换及保留用户数据卸载通过，原项目及共享用户配置哈希保持不变。下载后请按发行附件 SHA256SUMS.txt 校验。SDK、模型及私人素材不随本版发布。

# WebVideo+ 1.2.0 · Terre / WebGAL 4.6.5

最终 Windows 安装、GUI 与成片验收记录随发布资产提供；源码检查不替代本机验收。

自动更新通道面向 WebGAL 4.6.5。WebGAL 4.6.4 / MyGO 3.2.1 保留 1.1.7 最终稳定通道；本版内部保留的向后兼容路径不意味着旧用户应自动升级。

- 与 1.1.7 共用安装器产品检测：误选 Craft 会停止操作并提供已验证的 Craft 专属正式安装器下载
- 切换路径立即清除旧链接，循环快捷方式与过期自动扫描安全停止

- 增加 Terre 4.6.5 宿主与对应官方 WebGAL 4.6.5 导出运行时适配，保留 4.6.4 与 MyGO 3.2.1 路径
- 保留 1.1.6 的按语句手动切点、` ;CutHere` 注释切点与“包含立绘”控制，以及 Live2D 同名动作切段修复
- 按实际引擎版本处理图片差分、`transformFrom`、资源等待与启动语言；不将 4.6.5 项目静默降为 4.6.4
- 从当前项目的已就绪预览捕获语言，并将语言纳入共享计时与缓存校验；没有预览证据时使用有效项目默认语言

完整验证范围见 [适配记录](../../WEBGAL_4_6_5_ADAPTATION.md)。

- 修复管理器隔离测试参数 `--no-recent true`：安装、修复与卸载不再读取、写入或删除共享的最近安装记录。

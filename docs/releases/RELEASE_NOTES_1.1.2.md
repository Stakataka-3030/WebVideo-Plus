# WebVideo+ 1.1.2 发行说明

修复使用 Terre 自定义用户数据目录或便携模式时，WebVideo+ 仍按默认目录寻找项目、场景和 MyGO 引擎的问题。安装器现在读取 Terre 当前的数据目录；对旧安装留下的默认游戏目录，导出服务会在启动时纠正。创建任务时还会优先核对 Terre 当前目录，避免读取旧位置中的同名工程副本。

场景或 MyGO 引擎确实找不到时，导出面板会给出更明确的提示；点击“打开日志”可查看 WebVideo+ 配置目录、Terre 当前目录及实际尝试过的场景或引擎位置。此类错误发生在任务入队前，因此记录在服务日志中。

本版保留 1.1.1 的安全切段修复。原版 WebGAL / Terre 适配基线仍为 **4.6.4**；4.6.5 适配仍在独立实验分支中。

- 产品版本：`1.1.2`
- 安装器 Win32 版本：`1.1.2.0`
- 内部版本：`0.8.6`
- 导出内核：`0.6.46`

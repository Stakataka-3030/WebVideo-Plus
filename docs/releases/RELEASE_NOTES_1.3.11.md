# WebVideo+ Terre 1.3.11 候选

状态：仅本地未发布候选。安装器 1.3.11.0，导出内核 0.6.67，内部开发标识 0.8.17。未创建 Release、标签或远程提交。

## 1.3.11（未发布候选）

- 从 4.6.4 LL 开发分支选择性移植通用修复，不引入 LL 引擎、3D 模型、动作或资源协议。
- ID 补全默认不覆盖已有 ID；多套在场立绘时不猜测对白关联，保留 4.6.6 图片差分支持。角色映射表及同名歧义规则未改。
- 导出识别 Opus / Vorbis 循环标签，修正重复片段 PTS；离线预演与渲染保持静音。
- 计时结果优先读取排队时的 sourceHash；共享素材显示库名，错误响应保留允许来源的 CORS 头。
- Terre 便携安装为高级设置中的可选项，默认收起；常规安装和已安装模式保持不变。FFmpeg 更新加入有界重试与恢复。

## 用户界面影响

普通编辑与导出布局不变。一键 ID 补全面板的“覆盖已有 ID”默认关闭；共享立绘地址显示可读库名。便携安装仅在安装器高级设置展开后出现，默认不启用，Craft 不增加该选项。未使用 LL 引擎的用户无需调整工程。

## 保留与验证边界

保留目标分支的 WebGAL 4.6.5 / 4.6.6 兼容保护、animation v2、图片差分、JPEG / PNG 兼容捕获、预览语言启动配置与 Steam 宿主识别。未同步 LL / GLTF 专属逻辑，未改角色 ID 表。

本地后台检查记录见 [移植核验](../verification/common-port-466-20261110.md)。后台测试与本地构建不替代发布前精确提交 CI 与真实宿主完整验收。

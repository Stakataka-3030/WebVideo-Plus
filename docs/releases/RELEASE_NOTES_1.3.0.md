# WebVideo+ 1.3.0 · WebGAL 4.6.6

本版适配官方 WebGAL / Terre 4.6.6，精确核验官方引擎与编辑器发布包。4.6.5 最终稳定通道为 1.2.1，4.6.4 / MyGO 3.2.1 为 1.1.7，Craft 仍使用独立 1.1.12.0c。

兼容模式新增可选 PNG 无损截图，默认 JPEG。PNG 只消除截图压缩，最终 H.264 仍为有损编码，其他编码模式与透明图层语义保持不变。

适配 animation v2 关键帧格式和动画注册接口，保留 v1 累积时长。适配 Live2D 内存预留：指定初始内存时避免被引擎后续预留重置；使用默认值时保留引擎行为。编辑器、导航、资源预检及导出使用独立 4.6.6 profile。

修正规划器未登记动态命名动画导致时长为零的问题。动画运行中或模型有后续动作变更时，切段按需要重放完整场景历史，保留原生动画驱动、动作选择、保存姿态和物理状态；手动切点及输出帧数不变，自动并行继续考虑预演成本。复杂场景可能增加预演耗时。模型退场继续使用其原始出生时刻。分析任务结束后的 WebView2 短暂文件锁采用最长 5 秒的有限缓存清理重试。

产品版本 1.3.0，安装器 Win32 1.3.0.0，内部标识 0.9.2，导出内核 0.6.55。

本轮已通过 169 项 Node 回归（零跳过）、221 项三个精确引擎适配断言、24 种编辑器补丁组合、212 项设置/切点断言及 69 项安装/更新分流断言。直接提取官方 4.6.6 函数验证动画、Cubism2 纹理转换/预加载及内存预留，真实 Chromium / Pixi 的 16 种场景、每种 6 帧像素检查通过。

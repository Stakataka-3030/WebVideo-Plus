# WebVideo+ 1.3.0 · WebGAL 4.6.6

本版适配官方 WebGAL / Terre 4.6.6，精确核验官方引擎与编辑器发布包。4.6.5 最终稳定通道为 1.2.1，4.6.4 / MyGO 3.2.1 为 1.1.7，Craft 仍使用独立 1.1.12.0c。

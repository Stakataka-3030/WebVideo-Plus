# WebVideo+ 1.1.5 发行说明

## Live2D 分段动作恢复

修复同一模型反复指定同名动作时，分段规划错误地把后一次命令当作新动作起点的问题。WebGAL 保留同名动作原本的播放进度，即使该动作已经结束；导出器现在采用相同语义。更换模型、位置或实际绘制范围时仍会建立新的模型生命期；数值相同但写法不同的 bounds 不会产生虚假的重载。

空动作停止后的保持姿态也纳入恢复。Cubism2 重建停止前已经保存的参数；Cubism3/4 在停止前最后一帧求值并保存姿态。未改变模型的物理预热时长，也没有将此修复解释为所有切口抖动的统一原因。

## 强制手动切点

导出高级设置新增“分段切点 → 手动指定切点（强制）”。可以输入整数帧号（可带 f）、带 s 的秒数或 MM:SS / HH:MM:SS 小数秒，用逗号或空白分隔。时间向上取整到帧，排序后合并重复帧。切点相对于本次成片的首帧；选择场景或剧本范围后仍从本次输出的 0 帧开始计数。

手动模式只在指定位置切段，不自动补点、不移动切点、不因安全策略或预热成本删点。留空就是单段。并行数仅限制同时运行的任务数。起点、终点和超出输出范围的切点会报错；起止边界由导出器包含。

切点可以位于 Live2D、Pixi 或其他持续演出中，因此复杂状态的连续性不作保证。既有恢复和预热仍会尽力执行，但不会用恢复安全性决定手动切点是否生效。自动模式继续使用原安全规划。CLI 对应 --segment-cut-mode manual 和 --manual-cut-points。

## 验证与边界

包含无需私有模型的动作生命期回归、锁定 WebGAL 4.6.4 运行库的语义对照，以及真实 C# 手动切点解析/规划检查。另用授权提供的 Cubism2 SDK 和模型做数值对照：普通、重复同名动作和停止动作场景的 157 个绘制对象在切口处顶点完全一致。该验证采用数值模型更新，不包含完整浏览器像素渲染或缺失的原始剧本；Cubism3/4 仅声明便携队列测试。详细复现方法见 [Cubism2 测试说明](../CUBISM2_TESTING.md)。

WebGAL / Terre 适配基线仍为 **4.6.4**；4.6.5 适配不包含在本版中。

# WebVideo+ 1.3.1 · WebGAL 4.6.6 / #31 配音解析修复

本版仅面向 Terre / WebGAL 4.6.6。修复 [#31](https://github.com/Stakataka-3030/WebVideo-Plus/issues/31)：旧式 `-配音.wav` 后多个参数分隔空格不再导致导出声音与立绘口型静默丢失。WebGAL 原始解析器和对白文本保持不变。

扫描、快照、媒体字典和导出按浏览器资源 URL 的边界规则处理：在百分号解码之前移除整个 URL 末尾原始 C0/ASCII 空格和原始 TAB/CR/LF；不删除文件名内部空格、全角空格或解码后的合法字符。编码路径只解码一次，`%20` 与 `%2520` 不混同。编码的路径段末尾 ASCII 空格及查询前真实空格不会误配到无空格文件，在 Windows 给出明确不支持诊断。

配音、音乐资源按其资源类别取得媒体信息，不再仅依赖文件扩展名；缺失资源、无效时长、无音轨媒体和缺失配音元数据明确报错，避免继续静默输出零时长音轨。

**#31 仅在 1.3.1 修复，1.1.x / 1.2.x 不回移，此问题在这两个维护系列不予修复。** 4.6.4 / MyGO 3.2.1 仍使用 1.1.7，4.6.5 最终版仍为 1.2.1，Craft 保持独立 1.1.12.0c。本次不修改旧版代码或发行资产。

保留 1.3.0 的 PNG 选项、默认 JPEG、animation v2、Cubism2 纹理修复和切段恢复。PNG 的无损保证仅适用于截图格式，后续有损视频和跨浏览器绘制不保证位级相同。

产品版本 1.3.1，安装器 Win32 1.3.1.0，内部标识 0.9.3，导出内核 0.6.56。详细实际测试范围、源码提交、CI 和公开下载核验见发行附件 `TEST-REPORT.md`、`BUILD-PROVENANCE.json`、`PUBLIC-VERIFICATION.json`；下载后按 `SHA256SUMS.txt` 校验。SDK、模型、私人素材及原始个人路径日志不随发行上传。

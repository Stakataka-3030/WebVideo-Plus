# WebVideo+ 1.1.3 发行说明

导出界面的高级设置新增“每进程 Live2D Core 初始内存”。默认保持 WebGAL 原有行为；需要时可手动填写 16–1024 MiB。导出器会在时间分析和每个并行渲染进程加载模型之前尝试应用该值，并将是否生效写入任务诊断记录。当 Cubism Core 已加载但未提供该接口时，手动设置会明确报错，改回默认即可继续导出。

这个数值是每个进程请求的初始分配量，**不是进程内存上限**，实际占用可能更高，并行进程的内存需求也会叠加。它不减少模型贴图显存占用，也不保证解决所有多模型卡顿或卡死问题。建议先以较小值测试具体工程。

本版使用复制的短场景完成了默认设置分析、64 MiB 双进程导出及 16–1024 MiB 边界校验；尚未把 1024 MiB 作为实际导出配置运行，也未完成大型私有工程的整片验收。

WebGAL / Terre 适配基线仍为 **4.6.4**；4.6.5 适配不包含在本版中。

- 产品版本：`1.1.3`
- 安装器 Win32 版本：`1.1.3.0`
- 内部版本：`0.8.7`
- 导出内核：`0.6.47`

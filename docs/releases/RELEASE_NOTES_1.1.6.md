# WebVideo+ 1.1.6 发行说明

## 按语句指定切点

手动切点可在现有时间线选择器中多选语句，切点位于所选语句开始之前。也可在剧本文本中单独写一行 `;CutHere`，在下一条实际执行的语句之前切段。注释由 WebGAL 忽略，不会产生新的剧情指令。

两种来源可以同时使用，最终按实际执行时间换算为帧并去重。需要在高级设置中明确启用手动切点；自动模式不读取这些标记来改变分段。手动模式只使用指定边界，不补自动切点，也不按状态恢复、安全窗口或预热成本移动切点。旧版数值切点仍可通过命令行、API 和既有排队任务使用；新版导出面板使用语句选择与剧本标记。

## 舞台导出可排除立绘

“导出舞台”在“包含背景”下新增默认勾选的“包含立绘”，可以独立选择四种组合。取消勾选时，`changeFigure` 对象仍按原剧本加载、更新和执行演出，仅从最终输出画面中排除，不通过删除语句或设为透明来改变动画求值。

该选项仅作用于舞台导出；旧任务和未提供新字段的请求仍默认包含立绘。输出格式继续由是否包含背景决定；取消背景时使用现有 MOV / WebM Alpha 路径。缓存签名和输出记录包含立绘选项，避免误用不同内容的分片。

## 版本与适配范围

保留 1.1.5 的同名 Live2D 动作、停止姿态与强制切点修复。WebGAL / Terre 适配基线仍为 **4.6.4**。

- 产品版本：`1.1.6`
- 安装器 Win32 版本：`1.1.6.0`
- 内部版本：`0.8.10`
- 导出内核：`0.6.50`

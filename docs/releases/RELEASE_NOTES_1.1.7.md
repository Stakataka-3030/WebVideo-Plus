# WebVideo+ 1.1.7 · WebGAL 4.6.4 最终稳定版

本版本以已发布的 1.1.6 为基础，维护安装器、下载通道与隔离管理操作。导出内核仍为 0.6.50；WebGAL 4.6.4、Terre 4.6.4 与可选 MyGO 3.2.1 基线不变。

- 误选 WebGAL Craft 的文件夹、程序或快捷方式时，安装器明确提示改用 WebVideo+ Craft，不会修改 Craft
- 下载按钮按 Craft 专属正式标签、兼容标记和已上传的同名安装器查找；不会使用全仓库 latest，也不会回退到旧测试包
- 同目录混有 Terre 与 Craft 时停止操作并要求使用独立目录
- 切换路径立即清除旧下载链接，忽略过期查找结果；循环快捷方式会安全停止
- 4.6.4 用户保留本通道；Terre / WebGAL 4.6.5 使用 1.2.0 通道，不能仅按最大版本号升级

安装器：`WebVideo+-Setup-1.1.7.exe`，Win32 版本 `1.1.7.0`，内部版本 `0.8.11`。

MyGO 引擎、模型及角色素材仍由用户现有安装提供，不随包分发。

最终安装包的校验值与 Windows 验收范围见随发行包提供的验证记录。

- 修复管理器隔离测试参数 `--no-recent true`：安装、修复与卸载不再读取、写入或删除共享的最近安装记录。

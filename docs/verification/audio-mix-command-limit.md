# 音频混合命令行长度修复

内核 0.6.70，适用于 Terre 1.1.18 / 1.3.12 与 Craft 1.2.4c。现有 MyGO 结构兼容修复一并保留，未修改工程或基线插件参数。

## 执行合同

- 保留浏览器生成的 `audio-args.json` 格式及旧计划兼容性。C# `AudioMixer` 校验输入和标签后执行，视频 `JobRunner` 与纯音轨 `LayerExport` 共用该实现。
- 每个 FFmpeg 滤镜图使用固定依赖支持的 `-/filter_complex` 从 UTF-8 文件加载。输入列表另按 Windows 引号转义及 process-guard 包装计算长度，上限 24,000 字符，每步最多 32 条输入。超过上限时递归合并，单条路径仍无法容纳时明确失败。
- 各源先恢复原始整体图的声道及采样率协商，再执行原始 trim、volume、fade、delay 和 muteWindows。任一循环标签中的显式 48 kHz resampler 会约束全图采样率，不能仅按第一条源文件猜测。
- 批次使用 64 位浮点 PCM / Wave64，关闭 amix normalize，不在中间批次限幅、整数量化或重采样。原 video-music limiter 只在最终混音执行一次，最后才转 48 kHz。纯音轨交付仍为 pcm_s16le，视频仍按原流程编码音频。
- 最终再按样本时钟约束时长，防止 FFmpeg 9 的输入 seek / stream_loop 组合产生重复时间戳尾部。此类旧图的数值对照使用所请求的物理样本区间。
- 临时滤镜和浮点批次在成功及失败时清除。纯音轨裁切用的完整混音也在 finally 清理。保留每步的长度、输入数、错误日志，失败时另保留滤镜和参数 JSON。

## 复现与验证

先运行 `build.ps1`，再运行 `tests/audio-mixer-native.ps1 -FfmpegDirectory <固定 FFmpeg 目录>`。无需浏览器或安装覆盖，全部程序隐藏窗口执行。CI 纳入相同回归。

固定 FFmpeg 为 `n9.0.2-17-g2a571b6068-20260930`。200 条长路径场景中，旧命令 56,950 字符，单独输入列表 39,919 字符，真实 Windows 启动返回 ENAMETOOLONG。修复后为 8 步，最长约 7,100 字符。1,025 条音轨验证递归缩减。

覆盖原始短图、源偏移、mono / stereo / 5.1、32 / 44.1 / 48 kHz、标签与 stream_loop、淡入淡出、muteWindows、超过满幅的中间结果抵消、video-music 全局 limiter、超 32K 滤镜、纯音轨范围与无声、第二批失败、畸形缓存计划及 AAC 视频封装。与原整体图对照最大样本误差约 3.58e-6，普通多声道及循环样本约 4e-8 以下。短图数值一致。

## 验证边界

混合顺序与浮点累加精度会带来上述舍入差异，不承诺比特一致。浮点中间文件需要额外磁盘空间，多小时素材及超 4 GiB 文件没有实测，本次使用 Wave64 / RF64 避免标准 WAV 容量上限。未用私人长篇工程执行图形界面导出，合成音视频验证不能替代完整实际工程验收。安装器与发布校验另行记录。

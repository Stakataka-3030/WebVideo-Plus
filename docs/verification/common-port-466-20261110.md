## 实施范围

- ID 面板默认不覆盖已有 ID；多套在场立绘时保守提示，不猜测对白关联；同名说话人仅在在场候选唯一时补全，多个候选保守提示，忽略在场状态时亦不猜选；保留图片差分、槽位效果前瞻和明确指定位置。角色 ID 表与别名映射数据保持原样。
- Opus / Vorbis 循环标签贯通媒体探测、工作计划和 FFmpeg 混音；循环后重建样本时钟，避免补静音掩盖短缺。
- 排队及重试保存 canonical sourceHash，计时 API 在源快照清理后仍可核验结果；旧任务保留兼容回退。
- 离线 WebView2 导出静音，保留 4.6.6 语言启动参数；共享立绘显示库名和路径，保留原始引用；允许来源的资源错误响应有 CORS 头，非允许来源仍拒绝。
- 便携安装是默认折叠的高级设置项，默认关闭；安装模式固定，移动后重新解析路径、实例与任务。保留常规安装、Steam 识别与 4.6.6 运行时门槛。FFmpeg 提交加入有界重试，失败时保留并恢复旧工具。
- 不引入 LL / GLTF 引擎、模型、动作、3D 扫描或资源协议。Craft 不移植便携安装。

# WebVideo+ Craft 1.2.2c

草案，待验证，尚未发布。

适配官方 Windows x64 Craft 1.0.0。安装器 1.2.2.0c，Win32 文件版本 1.2.2.0，导出内核 0.6.66，产品基线 1.3.10。

本版拟同步两项导出修复：

- 保护已请求 Live2D 表情的异步加载与模型销毁时序，并补齐关键资源等待。
- 在导出任务副本中跳过游戏自动快速存档，减少加速预演反复复制回溯记录和排队写入存储的开销。正常游戏的自动存档与手动存档保持原有行为，不改写源工程。

感谢 [NijiharaTsubasa](https://github.com/NijiharaTsubasa) 提供 planning 阶段自动存档性能热点的反馈及禁用后加速的验证线索。

宿主与工程引擎继续按精确构建校验，不扩大宿主允许列表。预演提速取决于剧本、素材和运行环境，不承诺统一倍数；独立修复的验证记录不能代替合并后 Craft 安装器的验收。

## 发布前待验证

- 隔离原入口安装及升级、实际宿主启动、基本编辑和预览、短片导出、卸载恢复及退出清理。

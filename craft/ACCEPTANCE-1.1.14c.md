## 实现及边界

移植适用 src/browser 变化：固定 4.6.6、动画 v2 注册/回放/切段、现代
Live2D 时序、4.6.5 Cubism2 纹理回补、字形裁切、C0/ASCII 尾部资源 URL
归一化、PNG/JPEG 捕获、缓存释放、手动数值及语句切点、`;CutHere`、
Core 内存、自动/手动/BGM 计时。保留 Craft 的项目 VFS 快照、严格实际
运行时、独立内核状态和既有功能入口。Terre 的全局目录发现、偏好存储及
自动备份策略未导入 Craft；更新提醒使用独立 Craft 状态文件，原生安装器
与应用共用，自动提醒可暂停，手动检查保留。

仅原 EXE 替换挂载；官方 Craft 签名源与公钥保留。误识别产品时引导到
相应产品。官方安装运行策略沿用此前授权，三项未完成的真实 NSIS/观察器/
自动重挂载验证标志仍为 false。

## 本轮证据

证据位于工作区相邻 `evidence/parity-1.1.14c/`，真实项目仅使用自建
`qa/parity14`。实际测试通过该实例所有权验证的 CDP 与产品桥执行，未把
人工鼠标/键盘或其他用户窗口操作当作验证。

- 完整 Node 回归 894/894，零失败零跳过；后续表单相关 67/67。
- 实际产品程序集双运行时 137、MyGO 9、字体/资源环境 61、缓存释放 5
  检查；原生 Setup 窗体动作与 560px/100–200% 布局通过。
- 4.6.6、4.6.4、MyGO 严格取消终态为 canceled/canceled/cleanupComplete=true。
  独立 ffprobe、440Hz 解码、soft 字幕提取、burn 像素验证通过。
  4.6.5 初始旧取消探针只确认请求，不能单独证明清理终态。
- 真实 UI 的待入队回复取消、按钮恢复、迟到 ID 单独取消、关闭再开、
  再次入队及渲染中重复取消三组通过。所属 FFmpeg partial 已实际存在时
  合并阶段取消通过：partial 删除、邻文件与已完成片段保留。
- 新编译 QueueService 的取消重启恢复通过：活进程等待、PID/启动时间
  身份、归属 partial 清理和已完成输出保留。不会用管道异常冒充进程退出。
- 复杂动画 492 帧/16.4 秒；并行与串行 18 个解码帧含两处切点前后完全
  相同，实际角色移动约 95px。Live2D PNG 525 帧/17.5 秒、手动 90/267
  帧切点及 `;CutHere`/语句合并；规划及三个渲染进程 Core 内存均实际
  applied=true / effectiveMiB=64。
- 手动计时 7.7 秒、项目内 BGM 适配 20 秒真实成片；原生创作的 Anogo
  预览/应用/撤销与备份恢复/撤销通过。Craft 原生与 Node 提醒文件互读通过。

最终产物哈希、安装/更新/卸载完整矩阵、最终字节复测及历史失败记录由
外部 FINAL-REPORT.md 固定，避免把自包含安装包内文档当作其自身哈希证明。

# WebVideo+ Craft 1.1.17c

安装器 1.1.17.0c，导出内核 0.6.61。支持官方 Windows x64 Craft 1.0.0-rc.1 / 1.0.0-beta.2。

- 高级导出设置可选择具体 GPU，导出结果记录实际渲染器信息。
- 精确捕获文本框循环动画改为可选，默认关闭。
- 导出面板增加日志文件夹入口及可展开的错误详情。
- 修复变量音量导出异常和队列输出文件名大小写冲突。

Craft RC1 最终维护版；正式版 Craft 请使用对应适配版本。

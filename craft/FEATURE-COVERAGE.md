# WebVideo+ Craft：功能适配与验证范围

本实现保留 WebVideo+ 独有的创作与成片功能。Craft 原生的文本／可视化编辑、普通命令分类、收藏、原始语句组、定位及撤销继续复用；它们不替代全场 ID 推断、批量操作或真实故事计时。

下表中的“已实现”指有真实控制器和界面入口，不能理解为已经在所有实际工程中完成实机验收。宿主未绑定的能力会显示具体不可用原因；不会以空结果、估算时间或别的模型结果冒充成功。

## 数据与编辑边界

- 作者操作读取当前 Craft 编辑缓冲区，包括未保存内容；先生成原文／结果预览，再通过 `snapshot + revision + commit` 提交一个原生可撤销事务
- 文件、工程、源文或 revision 变化后，旧预览失效。创作功能不直接覆盖场景磁盘文件，不替用户自动保存
- 使用 Craft 官方依赖的 `webgal-parser@4.6.5` 原始 UMD 及同版源码，保留原始物理行范围、BOM、CRLF、未改语句、未知参数及行内注释。旧引擎按能力门控；没有确认的较新语法不贸然改写
- 元数据使用前镜像比较后写入；复核标记与场景源码分开。生成内容标为待复核，文本或上下文改变后不会默默继承已确认状态

## 功能对照

| 功能 | 当前实现与入口 | 原生复用／验证边界 |
|---|---|---|
| 全场 ID 补全 | 路径／别名推断、已有 ID 保留或明确覆盖、在场检查、离场拆分、默认位置换角退出、效果目标重映射及同一连续组前向引用；歧义项目列警告 | 一次源文预览、一次 Craft 事务。不是逐字段自动补全的替代品 |
| 预位表情 | 选中对白按 ID 或位置找到在场模板；默认跳过旁白、画外音及已预位项；可明确解锁／强制；位置对白可转换为 ID | 保留多行模板；新增行待复核。原生字段编辑仍可修改结果 |
| 自动离场 | 对选定入场检测同位置被替代对象，插入保留 `when` 的离场行 | 根据下述已核实差分语义，差分不是一律新入场，也不是一律不入场 |
| 批量 `-next` | 类型筛选与显式语句集合；已有参数不重复添加；对白默认关闭；全屏文本不误加 | 不改变 Craft 新命令默认值 |
| 批量添加滤镜 | 背景／立绘独立数值片段、可选动画、已有变换警告、共享库读取及命名保存 | 目标从实际语句解析；数值库不夹带目标或命令控制字段 |
| 替换／删除已有滤镜 | 连续同目标语句的字段子集识别、优先较大匹配；仅替换匹配字段，保留其他变换与未知参数；整句删除另行选择 | 不把不同 `transformFrom` 写入模式混成同一序列；原参数不静默迁移 |
| 参数化演出预设 | 分类／搜索、共享预设及手动保存、单目标重绑定、多目标关系保留、已应用序列识别 | 普通原始片段继续使用 Craft 原生语句组，不复制一套普通片段管理器 |
| 单行提示 | 新建、时长修改、确认后取消旧单选跳转并转换；100–60000 ms；成对移动、复制和删除；多选转换拒绝 | 专用标签唯一且受成对保护。计时预览必须使用专用运行时桥，普通跳转不冒充计时预览 |
| 制作导航 | 文本／说话人／类型筛选、继承说话人、变换字段摘要、连续组、静态分支标记、预设识别、任意集合与行范围选择 | 定位／普通预览使用 Craft 原生能力；物理行范围覆盖多行逻辑语句 |
| 制作检查与复核 | 缺少先前在场 ID、连续三句重复动作／表情、损坏提示对；待复核／已确认／忽略；生成内容记录 | 不重复 Craft 语法和资源诊断；复核锚点含正文与前后文 |
| 原长多轨音乐 | 最多 64 首／播放器，单轨不重叠、跨轨并行，原生文件选择，起点／轨道／音量／启停编辑，schema 2 配置 | 实际文件时长由内核读取；保存前备份及前镜像校验；不缩放、裁切或伪造歌曲时长 |
| 旧音乐配置迁移 | 根据实测多场景起点把旧场景相对配置转换成全局时间线 | 缺少真实时长、场景或足够播放器时明确拒绝 |
| 实际时间与片段 | 内核运行测量；源文、速度和依赖指纹校验；任意不连续选段绑定源快照 | 不使用 Craft 动画关键帧长度冒充故事时长；保存／预览状态须满足宿主桥要求 |
| 配乐匹配速度 | 读取真实 textSpeed／autoSpeed；可选调整维度；最多两次实测校准；报告误差或不可达 | 不更改音乐长度。速度只在会话保存时，界面明确说明，不承诺永久持久化 |
| Anogo 导入 | JSON／YAML、严格字段校验、角色映射、可选动作／表情映射（默认关闭）、编译预览后追加 | 未知或不完整映射保留警告；拒绝路径穿越、对白伪装命令和参数注入 |
| AI 小说骨架 | 显式提供商配置／发送确认、原文分类和基础舞台两阶段、单人／双人选择、进度、取消、预览后追加 | 模型输出仍经完整性／素材／舞台验证；迟到、取消或陈旧源文不追加。没有在验收中真实发送用户文本或密钥 |
| 字幕后处理 | 原生选择 SRT／ASS／SSA；视频起点、手动秒数、实测语句或音乐锚点；soft／burn 选择 | 源 hash 和导出范围校验。soft MP4 不承诺保留 ASS 样式；内容编辑仍使用外部字幕工具 |
| 视频与选段导出 | 真实服务任务、状态／取消；不连续片段各自建立绑定源 hash 的任务 | 不直接读旧磁盘场景覆盖当前编辑器；需要快照时明确要求满足保存状态 |
| 备份与恢复 | 打开工程与整十分钟的两个固定自动槽（覆盖保留最新、失败重试）；场景／全故事 TXT／音乐备份读取；恢复前再保存当前版本；场景用原生事务，音乐用前镜像校验 | 全故事恢复明确逐个选择场景，不声称已有跨文件原子撤销。完整素材不属于“全故事 TXT 快照” |
| Craft 更新协调 | 官方检查／下载入口；协调安装前再次检查未保存文档和运行任务 | 原生安装观察／接续能力未经核实时保持禁用；保留 Craft 自带更新入口，不宣称接续已验证 |

## 差分立绘与写入模式的实际语义

已对照官方 WebGAL **4.6.5 tag**，提交 `d0318e6c4cdb8b04bb5d891f40368cff3c6efc85`：

- 已有图片的 `changeFigureDiff` 只替换图片地址及整组口型／眨眼图，保留原位置、变换和入退场设置
- 没有源立绘，或目标为空／`none` 时，回退普通 `changeFigure` 入退场语义
- 源或目标是 Live2D／Spine 时整句跳过，不能更新分析中的虚构在场状态
- 原本的默认位置立绘被补成自定义 ID 后，后续位置差分同步重映射；默认位置换角时保留替换关系，避免叠出旧角色
- `transformFrom=current` 与 `default` 不等价；本适配保留明确已有参数，识别多段滤镜时不跨模式合并

来源：[changeFigureDiff.ts](https://github.com/OpenWebGAL/WebGAL/blob/d0318e6c4cdb8b04bb5d891f40368cff3c6efc85/packages/webgal/src/Core/gameScripts/changeFigureDiff.ts)、[figureAssociatedAnimation.ts](https://github.com/OpenWebGAL/WebGAL/blob/d0318e6c4cdb8b04bb5d891f40368cff3c6efc85/packages/webgal/src/Core/gameScripts/figureAssociatedAnimation.ts)。解析器来源与 MPL 源码在 `features/vendor/README.md` 中说明。
